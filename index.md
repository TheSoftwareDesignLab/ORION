## What is ORION
ORION is a modular platform for Space Domain Awareness focused on data integration, orbital analysis, and automated reporting.

---

## Key Features
- Satellite catalog processing (SATCAT module)
- Orbital data fusion
- Automated reporting system
- Scalable data pipeline architecture
